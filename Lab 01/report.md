# Lab 01 Report – Git & Development Environment Setup

## Reflection

In this lab, I learned how to set up a professional development environment using Visual Studio Code and Git. I configured my Git identity and successfully connected a local repository to a remote GitHub repository. Working with commands like `git add`, `git commit`, `git push`, and `git pull` gave me a clear understanding of the version control workflow. I also practiced creating and switching between branches, which showed me how parallel development works in real projects. Finally, merging the `experiment` branch into `main` demonstrated how isolated changes can be safely integrated into the main codebase.
